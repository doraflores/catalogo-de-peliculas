# Catálogo de Películas
Esté proyecto fue desarrollado para la Práctica #3 del Lab de POO.
El proyecto permite gestionar una lista de películas , agregarlas y realizar búsquedas por título.

## Intrucciones de compilación y ejecusión
Para ejecutar el programa desde la terminal, sigue estos pasos desde la raíz del proyecto:

1. **Compilar los archivos:**
   Navega a la carpeta del proyecto y ejecuta:
   ```bash
   javac src/*.java
Ejecutar el programa:

(Asumiendo que tu clase principal es Main):
java -cp src Main
